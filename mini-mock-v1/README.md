# Mini Mock v1

This mini mock is a calibration tool for the course. It is not a full official practice exam and it is not a guarantee of the real exam distribution.

## Official Exam Context

The certification exam uses scenario-based multiple-choice questions. Each question has one correct answer and three distractors. The official scored domain weights are:

| Domain | Official Weight |
| --- | ---: |
| Domain 1: Agentic Architecture & Orchestration | 27% |
| Domain 2: Tool Design & MCP Integration | 18% |
| Domain 3: Claude Code Configuration & Workflows | 20% |
| Domain 4: Prompt Engineering & Structured Output | 20% |
| Domain 5: Context Management & Reliability | 15% |

## Course Mini Mock Shape

This v1 mini mock has 20 questions weighted roughly:

| Domain | Questions |
| --- | ---: |
| Domain 1 | 5 |
| Domain 2 | 4 |
| Domain 3 | 4 |
| Domain 4 | 4 |
| Domain 5 | 3 |

The mix is intentionally close to the official weights while staying small enough to debrief in v1.

## How To Use It

1. Take the mini mock without checking the answer key.
2. Mark every miss by domain.
3. Write the failure layer you misread.
4. Write the distractor pattern that caught you.
5. Update the domain weighting study sheet before reviewing again.

Do not only memorize the correct letters. The value is in the rationale.
