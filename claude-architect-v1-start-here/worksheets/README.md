# Worksheets

Student-facing worksheet pack for lean v1.

- `tool-spec-worksheet.md`: design clear tool names, boundaries, inputs, outputs, and selection test cases before LAB-03.
- `strict-tool-use-checklist.md`: decide when strict tool input schemas are the right enforcement boundary before LAB-03.
- `reliability-checklist.md`: preserve context, provenance, escalation criteria, retry boundaries, and human review triggers for reliability scenarios.
- `trace-review-checklist.md`: read logs and traces before changing prompts, schemas, tools, or retry policy.
- `domain-weighting-study-sheet.md`
