# LAB-01 Gold Scaffold

## Goal

Set up the baseline repo, environment variables, and log routing patterns that later modules build on.

## Outcome

Students finish with a runnable local scaffold that:

- loads env values
- prints a request skeleton
- routes one sample `stop_reason`
- logs usage and next action

## Run

Starter:

```bash
cd starter
python3 src/app.py
```

Solution:

```bash
cd solution
python3 src/app.py
```
